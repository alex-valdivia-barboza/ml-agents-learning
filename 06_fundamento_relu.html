LECCIÓN 1.5 · FUNDAMENTO Las tres principales

ReLU

La activación más simple de todas, max(0, z), y la más usada hoy en capas ocultas. Por qué funciona, por qué necesita otra inicialización, y su problema propio: las neuronas muertas.

1. La función

06_activation_functions.py · líneas 55–60
def relu(z):
    return np.maximum(0, z)                # 0 si z es negativo, z si es positivo

def relu_derivada(z, a):
    return (z > 0).astype(float)           # 1 si z > 0, 0 si no
relusu derivada (punteada)

ReLU (Rectified Linear Unit) y su derivada: 0 a la izquierda, 1 a la derecha.

z        = [-3. -1.  0.  1.  3.]
relu     = [ 0.  0.  0.  1.  3.]
derivada = [ 0.  0.  0.  1.  1.]
  • np.maximum(0, z) compara elemento a elemento y se queda con el mayor. No confundir con np.max, que devuelve un solo número (el máximo de todo el array).
  • La derivada es la misma operación que step: 1 donde z > 0. ReLU es, literalmente, la función cuya derivada es step.
  • Fíjate que la derivada usa z, no a. Es el caso que anticipaba el fundamento del grafo computacional de la 1.3: por eso el forward genérico guarda también los zs.

2. ¿Cómo puede ser no lineal algo tan simple?

ReLU es lineal a cada lado del 0, pero tiene un quiebre en el 0. Ese quiebre alcanza: cada neurona ReLU es una “rampa” que empieza en su recta z = 0. Sumando muchas rampas con distintas orientaciones se puede aproximar cualquier forma, como una curva hecha de tramos rectos. En la red del script, ReLU separa los círculos con 100 %.

4. Otra inicialización: √(2/n)

06_activation_functions.py · líneas 118–119
factor = 2.0 if activacion == "relu" else 1.0
W = [np.random.randn(n_in, n_out) * np.sqrt(factor / n_in) ...]

ReLU apaga en promedio la mitad de las neuronas (las que tienen z < 0). Si se usara el mismo √(1/n) que para sigmoid, la señal se achicaría a la mitad (en varianza) en cada capa. El factor 2 compensa eso. Se llama inicialización de He.

El segundo experimento sugerido lo comprueba. Desvío de las activaciones en cada capa oculta, al inicio:

5. El problema propio: neuronas muertas

Del lado negativo la derivada es 0, igual que step. Si una neurona tiene z < 0 para todos los datos, nunca se activa, su delta siempre es 0 y sus pesos nunca cambian: está “muerta”. No hay forma de que vuelva sola.

06_activation_functions.py · líneas 212–214
_, acts_r = forward(X, W_r, b_r, "relu")
muertas = sum(int(np.sum(np.all(a <= 0, axis=0))) for a in acts_r[1:-1])

np.all(a <= 0, axis=0) revisa cada columna (cada neurona) y da True si su salida fue 0 para los 200 puntos. acts_r[1:-1] recorre solo las capas ocultas (sin la entrada ni la salida).

Con tasa 0.1, casi todas las muertas ya nacieron muertas (la inicialización las dejó con z < 0 para todo el dataset). Con tasa 1.0, los pasos grandes “empujan” más neuronas al lado negativo: 22, casi un cuarto de la red. Es el tercer experimento sugerido. La red igual llega a 100 % porque le sobran neuronas, pero en problemas difíciles es capacidad perdida.

Variantes: para evitar neuronas muertas existen versiones con un poco de pendiente del lado negativo, como Leaky ReLU (max(0.01·z, z)). En la práctica, ReLU con buena inicialización y una tasa razonable suele bastar.
