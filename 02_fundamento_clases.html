LECCIÓN 2.1 · FUNDAMENTO Qué es un agente

Clases y objetos: el entorno

Los scripts de redes usaban funciones y arrays. Los de agentes usan class: una forma de juntar datos y las funciones que trabajan con ellos. Explicado con la clase Entorno.

1. Por qué una clase

El entorno tiene datos (el tamaño y qué celdas están sucias) y operaciones sobre esos datos (preguntar si una celda está sucia, limpiarla, imprimir). Una clase los mantiene juntos.

Clase y objeto: una clase es un molde; un objeto es una cosa hecha con ese molde. Entorno es la clase; entorno = Entorno(tamano=3) crea un objeto concreto, con su propia cuadrícula. Se pueden crear muchos objetos de la misma clase, cada uno con sus datos.

2. El constructor: __init__

02_agent_hello_world.py · líneas 26–35
class Entorno:
    def __init__(self, tamano=3, prob_sucia=0.5):
        self.tamano = tamano
        self.grid = [
            [random.random() < prob_sucia for _ in range(tamano)]
            for _ in range(tamano)
        ]
  • __init__ se ejecuta automáticamente al crear el objeto. Prepara sus datos iniciales.
  • self es el objeto que se está creando. self.tamano = tamano guarda el valor dentro del objeto, como un atributo. Una variable sin self. desaparecería al terminar la función.
  • Al llamar Entorno(tamano=3, prob_sucia=0.5) no se pasa self: Python lo pone solo.

La cuadrícula: una lista de listas

self.grid se arma con dos list comprehensions anidadas. La de adentro arma una fila; la de afuera repite eso tamano veces:

random.random() < 0.5        # True con probabilidad 0.5: celda sucia
[ ... for _ in range(3)]       # una fila de 3 celdas
[[ ... ] for _ in range(3)]    # 3 filas

El _ es un nombre de variable que se usa cuando no importa su valor: solo hace falta repetir. Con la semilla 7 del script queda:

[[True,  True,  False],
 [True,  False, True ],
 [True,  False, True ]]

Es la misma idea que una matriz de NumPy, pero con listas de Python. Se accede igual por fila y columna: grid[1][2] es fila 1, columna 2 (True, sucia). La diferencia con NumPy es que hay que usar dos corchetes, no grid[1, 2].

3. Los métodos

Las funciones definidas dentro de la clase se llaman métodos. Todas reciben self primero, para poder leer y cambiar los datos del objeto:

02_agent_hello_world.py · líneas 37–49
def esta_sucia(self, pos):
    fila, col = pos                     # desarma la tupla (fila, col)
    return self.grid[fila][col]

def limpiar(self, pos):
    fila, col = pos
    self.grid[fila][col] = False

def todo_limpio(self):
    return not any(any(fila) for fila in self.grid)

def celdas_sucias_restantes(self):
    return sum(sum(fila) for fila in self.grid)
  • fila, col = pos es desempaquetado: si pos = (1, 2), queda fila = 1 y col = 2. Las posiciones se guardan como tuplas de dos números.
  • any(fila) es True si al menos un elemento de la fila es True. any(any(fila) for fila in grid): ¿hay alguna fila con alguna celda sucia? El not lo invierte: “todo limpio” es que no haya ninguna.
  • sum sobre booleanos cuenta los True, porque Python trata True como 1 y False como 0. Con la cuadrícula inicial da 6.

4. Usar el objeto

entorno = Entorno(tamano=3, prob_sucia=0.5)   # crea el objeto (línea 164)
entorno.esta_sucia((0, 0))                    # True
entorno.limpiar((0, 0))
entorno.esta_sucia((0, 0))                    # False
entorno.celdas_sucias_restantes()             # 5

Con el punto se accede a los atributos y métodos de un objeto, como con X.shape o X.T en NumPy (los arrays de NumPy también son objetos). Los agentes son clases con la misma estructura: __init__ con su posición inicial y un método percibir_y_actuar.
