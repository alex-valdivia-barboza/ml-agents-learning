LECCIÓN 2.2 · FUNDAMENTO Formular el problema

El mapa como datos

Cómo pasa el laberinto de un dibujo con caracteres a estructuras de Python que se pueden consultar: un set de paredes, dos tuplas, y la función sucesores.

1. El mapa como texto

08_agent_search_bfs.py · líneas 35–47
MAPA = [
    "############",
    "#S.....#...#",
    "#.####.#.#.#",
    ...
    "#...#...#.G#",
    "############",
]

Una lista de strings, uno por fila. Así se puede dibujar y modificar el laberinto a mano. Los bordes son todos pared, lo que evita tener que chequear si un movimiento se sale de la cuadrícula.

2. Leerlo: enumerate

08_agent_search_bfs.py · líneas 50–60
def leer_mapa(mapa):
    paredes = set()
    for f, fila in enumerate(mapa):
        for c, celda in enumerate(fila):
            if celda == "#":
                paredes.add((f, c))
            elif celda == "S":
                inicio = (f, c)
            elif celda == "G":
                meta = (f, c)
    return paredes, inicio, meta
  • enumerate(lista) recorre la lista dando a la vez la posición y el elemento: (0, "############"), (1, "#S.....#...#")… Un string también se puede recorrer, carácter por carácter.
  • Solo se guardan las paredes, en un set de tuplas. Las celdas libres son “todo lo que no es pared”.
  • La función devuelve tres cosas a la vez (una tupla), que la línea 63 desempaqueta: PAREDES, INICIO, META = leer_mapa(MAPA).

Resultado real: 75 paredes, INICIO = (1, 1), META = (9, 10).

Los nombres en mayúsculas (MAPA, PAREDES, MOVIMIENTOS) son una convención de Python para indicar valores que no deberían cambiar durante el programa (constantes).

3. Los sucesores

08_agent_search_bfs.py · líneas 75–80
MOVIMIENTOS = [(-1, 0), (1, 0), (0, -1), (0, 1)]       # arriba, abajo, izquierda, derecha

def sucesores(estado, paredes):
    f, c = estado
    return [(f + df, c + dc) for df, dc in MOVIMIENTOS if (f + df, c + dc) not in paredes]

Es celdas_vecinas de la 2.1 escrita en una línea con una list comprehension con filtro. Cambia el chequeo: en vez de “¿está dentro de los bordes?” pregunta “¿no es pared?”. Gracias al set, esa pregunta es instantánea.

El script la prueba en la línea 83:

Sucesores del inicio (1, 1): [(2, 1), (1, 2)]

Desde la S hay dos movimientos posibles: abajo y a la derecha. Arriba y a la izquierda son pared.

La única pieza que depende del problema: BFS, DFS y A* (lección 2.3) no saben nada de laberintos. Solo llaman a sucesores(estado) y comparan con la meta. Para resolver otro problema, se escribe otra función sucesores y el resto del código no cambia.

El orden de MOVIMIENTOS decide en qué orden se descubren los vecinos. Para BFS no cambia el largo del camino; para DFS cambia mucho (lo verás en el fundamento 6).
