LECCIÓN 1.5 · FUNDAMENTO En redes profundas

Una red de cualquier profundidad

Hasta la 1.4 cada capa tenía su propia variable (W1, W2…). Con 7 capas eso no escala. La Parte 3 guarda las capas en listas y recorre forward y backward con un for: el patrón de la 1.3, generalizado.

1. La red de esta lección

06_activation_functions.py · línea 158
TAMANOS = [2, 16, 16, 16, 16, 16, 16, 1]

2 entradas, 6 capas ocultas de 16 neuronas y 1 salida: 7 capas con pesos. Los datos son el círculo dentro de un anillo de la 1.2 (200 puntos).

2. Pesos en listas

06_activation_functions.py · líneas 115–122
def inicializar_red(tamanos, activacion):
    factor = 2.0 if activacion == "relu" else 1.0
    W = [np.random.randn(n_in, n_out) * np.sqrt(factor / n_in)
         for n_in, n_out in zip(tamanos[:-1], tamanos[1:])]
    b = [np.zeros(n_out) for n_out in tamanos[1:]]
    return W, b

El truco está en zip(tamanos[:-1], tamanos[1:]), que empareja cada tamaño con el siguiente:

tamanos[:-1] = [2, 16, 16, 16, 16, 16, 16]     # todos menos el último
tamanos[1:]  = [16, 16, 16, 16, 16, 16, 1]     # todos menos el primero
zip(...)     → (2,16), (16,16), (16,16), (16,16), (16,16), (16,16), (16,1)

Cada par es (entradas, neuronas) de una capa, la regla de shapes de la 1.2. Queda una lista de 7 matrices: W[0] es (2, 16), W[6] es (16, 1).

3. Forward: un for sobre las capas

06_activation_functions.py · líneas 125–134
zs, activaciones = [], [X]                     # activaciones[0] es la entrada
for capa in range(len(W)):
    z = activaciones[-1] @ W[capa] + b[capa]   # la salida anterior es la entrada
    es_salida = capa == len(W) - 1
    a = sigmoid(z) if es_salida else f(z)      # la salida siempre es sigmoid
    zs.append(z)
    activaciones.append(a)
  • activaciones[-1] es el último elemento de la lista: la salida de la capa anterior. En la primera vuelta es X.
  • Las listas zs y activaciones son el cache de la 1.3: guardan todo lo que el backward va a necesitar.
  • f es la activación elegida (sigmoid, tanh o relu), sacada del diccionario ACTIVACIONES. Así la misma función sirve para las tres.

4. Backward: el mismo for, al revés

06_activation_functions.py · líneas 141–147
dZ = (activaciones[-1] - Y) / n                # sigmoid + cross-entropy: a - y
for capa in reversed(range(len(W))):           # 6, 5, 4, 3, 2, 1, 0
    dW[capa] = activaciones[capa].T @ dZ       # entrada de la capa .T @ delta
    db[capa] = dZ.sum(axis=0)
    if capa > 0:
        dA = dZ @ W[capa].T                    # por W.T ...
        dZ = dA * df(zs[capa - 1], activaciones[capa])   # ... y por la derivada

Es literalmente el resumen de la 1.3: “por W.T, por la derivada” para retroceder, y “entrada.T @ delta” para el gradiente. Lo que antes eran dos bloques escritos a mano ahora es un loop.

  • Primera línea: la salida es sigmoid con cross-entropy binaria, la versión de 2 clases de softmax + cross-entropy de la 1.4. Su delta también es a − y.
  • Índices: como activaciones[0] es X, la entrada de la capa capa es activaciones[capa] y su salida es activaciones[capa + 1]. Al pasar a la capa anterior se usa la derivada de la activación de esa capa: con zs[capa − 1] y su salida activaciones[capa].
  • if capa > 0: la capa 0 no tiene capa anterior; no hace falta calcular un delta para X.

5. El entrenamiento

06_activation_functions.py · líneas 188–198
def entrenar(nombre, tasa_aprendizaje=0.1, epocas=1000):
    np.random.seed(0)                              # misma semilla para comparar
    W, b = inicializar_red(TAMANOS, nombre)
    for epoca in range(epocas):
        zs, acts = forward(X, W, b, nombre)
        dW, db = backward(Y, W, zs, acts, nombre)
        for capa in range(len(W)):
            W[capa] -= tasa_aprendizaje * dW[capa]
            b[capa] -= tasa_aprendizaje * db[capa]

El np.random.seed(0) dentro de la función hace que las tres activaciones arranquen con los mismos números aleatorios (solo cambia el factor de escala de ReLU). Así la comparación es justa: la única diferencia es la activación.

Con esta red ya se puede medir lo que en la 1.3 solo se insinuaba: qué tamaño tiene el gradiente en cada una de las 7 capas.
