LECCIÓN 4.2 · FUNDAMENTO Armar el bloque

Conexiones residuales y el bloque completo

x = x + f(x): en vez de reemplazar el vector, cada sub-capa le suma una corrección. Con eso, y con la red de cada posición (mlp), queda armado el bloque que se apila en todos los modelos de lenguaje.

1. La red de cada posición

mini_transformer.py · líneas 61–62
def mlp(x, p):
    return (x @ p["W1"] + p["b1"]).relu() @ p["W2"] + p["b2"]

Es la red de 2 capas de la 1.2, con ReLU (1.5) y una capa oculta 4 veces más ancha que D (128 neuronas con D = 32). Se aplica a cada posición por separado: x es (B, T, D) y @ W1 multiplica el último eje, así que las posiciones no se mezclan.

La división de trabajo del bloque es:

  • Atención: mueve información entre posiciones (“traer el dígito de 3 atrás”).
  • MLP: procesa lo que cada posición ya tiene (“con lo que traje, calcular qué responder”).

En los modelos grandes, el MLP tiene alrededor de dos tercios de los parámetros de cada bloque; se cree que buena parte de lo que el modelo “sabe” está guardado ahí.

2. Sumar en vez de reemplazar

mini_transformer.py · líneas 76–83
def bloque(x, p, H, causal=True, residual=True, norma=True, guardar=None):
    n1 = layer_norm(x, p["ln1_g"], p["ln1_b"]) if norma else x
    a = atencion(n1, p, H, causal, guardar)
    x = x + a if residual else a               # conexión residual
    n2 = layer_norm(x, p["ln2_g"], p["ln2_b"]) if norma else x
    m = mlp(n2, p)
    return x + m if residual else m            # otra

Sin las conexiones residuales, cada sub-capa reemplaza el vector: x = f(x). Con ellas, le suma algo: x = x + f(x). El vector x funciona como un “carril” que recorre todo el modelo, y cada sub-capa lee de él (a través de la norma) y escribe una corrección.

Los argumentos residual y norma (con valor por defecto True) solo existen para los experimentos: permiten apagar cada pieza y ver qué pasa.

3. Por qué ayuda tanto

  • Al inicio, el bloque casi no hace nada: si f(x) es chico, x + f(x) ≈ x. Un modelo de muchos bloques empieza comportándose como uno corto, y cada bloque aprende a agregar algo útil. Por eso init_bloque achica las matrices de salida (Wo, W2) con escala_salida = 1/√(2·N) (línea 92): cuantos más bloques, más chica la corrección inicial de cada uno.
  • El gradiente tiene una autopista: la derivada de x + f(x) respecto de x es 1 + f′(x). Ese “1” (la suma pasa el gradiente sin cambios, fundamento de la 4.1) hace que el gradiente de la pérdida llegue a los primeros bloques sin atravesar todas las multiplicaciones que lo achicaban en la 1.5. Es la misma idea que la “cinta” de las LSTM de la 3.5.

El experimento del fundamento 8 lo muestra: con 4 bloques, el modelo sin residuales ni normas no aprende la tarea.

El bloque completo: x = x + atención(norma(x)), después x = x + mlp(norma(x)). Dos líneas que se repiten 2 veces en el mini-GPT de la 4.3 y más de 100 en los modelos más grandes. Todo lo demás (tamaño, cantidad de cabezas, datos) es escala.

Con D = 32, un bloque tiene 12 576 parámetros: 4 096 en la atención (Wq, Wk, Wv, Wo), 8 352 en el MLP y 128 en las dos normas, más los embeddings (320 + 512), la norma final (64) y la salida (320), que llevan el modelo de la Parte 7 a 13 792.
