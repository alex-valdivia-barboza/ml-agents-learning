LECCIÓN 1.2 · FUNDAMENTO Cómo calcula la red

Los pesos como matrices (W1, W2)

En la 1.1 los pesos eran un vector w de 2 números. Con 4 neuronas ocultas hay 8 pesos en la primera capa: se ordenan en una matriz de 2 filas y 4 columnas. Qué significa cada fila, cada columna y cada shape.

1. De un vector a una matriz

En la 1.1, la neurona tenía w con shape (2,): un peso para x1 y otro para x2. Ahora hay 4 neuronas, y cada una necesita sus dos pesos. Se ponen lado a lado, una columna por neurona:

# 1.1: una neurona
w = [ w_x1,
      w_x2 ]        # shape (2,)
# 1.2: cuatro neuronas
         n0     n1     n2     n3
W1 = [[ w0_x1, w1_x1, w2_x1, w3_x1 ],   # fila de x1
      [ w0_x2, w1_x2, w2_x2, w3_x2 ]]   # fila de x2
# shape (2, 4)
Regla para leer cualquier matriz de pesos: shape (entradas, neuronas). Las filas son “de dónde viene” la señal y las columnas son “a qué neurona va”. W1[i, j] es el peso que conecta la entrada i con la neurona j.

2. Las cuatro piezas en el código

03_neural_network_2layer.py · líneas 113–118
def inicializar_red(n_entrada=2, n_oculta=4, n_salida=1):
    W1 = np.random.randn(n_entrada, n_oculta)    # (2, 4)
    b1 = np.zeros(n_oculta)                      # (4,)
    W2 = np.random.randn(n_oculta, n_salida)     # (4, 1)
    b2 = np.zeros(n_salida)                      # (1,)
    return W1, b1, W2, b2

W1(2, 4)82 pesos por cada una de las 4 neuronas ocultas.

En total la red tiene 17 parámetros (8 + 4 + 4 + 1). El perceptrón de la 1.1 tenía 3. Esos 14 de más son los que permiten dibujar una frontera curva.

Fíjate que W2 sigue la misma regla: (entradas, neuronas) = (4, 1). Para la capa de salida, las “entradas” son las 4 neuronas ocultas.

3. Los valores reales de tu red

Así quedan después de las 3000 épocas (es lo que imprime la Parte 5 del script):

W1 (2,4) =
[[-3.02 -4.99 -2.67 -5.85]     # pesos de x1 → neuronas 0, 1, 2, 3
 [ 4.94  2.97 -2.88 -6.36]]    # pesos de x2 → neuronas 0, 1, 2, 3
b1 (4,)  = [ 0.87 -0.81  4.12  2.51]
W2 (4,1) = [-5.67  6.3   5.74 -8.95]  b2 = [0.36]

Lee la columna 3 de W1: [-5.85, -6.36] con sesgo 2.51. Esa neurona calcula z = -5.85*x1 - 6.36*x2 + 2.51. En (0,0) da 2.51 (positivo → se enciende) y en cualquier otra esquina da negativo. Es el “detector de (0,0)” del fundamento anterior. Y su peso en W2 es -8.95: cuando se enciende, empuja fuerte hacia clase 0.

Cada recta gris del gráfico del script sale de una columna: el script la dibuja con x2 = -(W1[0, j]*x1 + b1[j]) / W1[1, j] (línea 226), la misma fórmula de frontera que usaste en la 1.1.

4. Por qué randn y no ceros

En la 1.1 los pesos arrancaban en randn * 0.1. Acá se usa randn sin achicar, y los sesgos sí arrancan en cero. Lo importante es que cada columna de W1 empiece distinta: si las cuatro neuronas empezaran iguales, aprenderían lo mismo y sería como tener una sola. Ese experimento está en el fundamento ¿Por qué los pesos iniciales no pueden ser iguales?
