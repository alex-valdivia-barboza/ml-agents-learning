El texto como datos

Para una red neuronal, una imagen ya era números (píxeles). Un texto no: es una secuencia de caracteres. Qué es un corpus, de dónde sale el de este módulo, y cómo lo carga corpus_es.py.

1. Lo que ya sabes

Del módulo 1: toda red recibe una matriz X de números. En MNIST, cada imagen de 28 × 28 se aplanó a 784 números. Ver ¿Cómo es MNIST?

Con texto no hay una conversión obvia. ¿Cuántos números es “En un lugar de la Mancha”? ¿Uno por letra? ¿Uno por palabra? Todo el módulo de PLN (Procesamiento de Lenguaje Natural) trata de responder bien esa pregunta. Esta lección da el primer paso.

2. El corpus

Corpus: una colección de textos que se usa para estudiar o entrenar. Puede ser un libro, millones de páginas web, o 80 reseñas. Lo que un modelo de lenguaje “sabe” sale de su corpus.

Este módulo usa dos, definidos en corpus_es.py para que todas las lecciones los compartan:

QUIJOTE

Texto largo y real

Don Quijote de la Mancha, de dominio público: 2.1 millones de caracteres, unas 384 000 palabras. Para estadísticas, n-gramas y embeddings.

RESEÑAS

Texto corto etiquetado

80 reseñas escritas para el curso, 40 positivas y 40 negativas. Para clasificar (lección 3.2).

3. Cargar el Quijote

corpus_es.py · función cargar_quijote
def cargar_quijote(carpeta="data"):
    ruta = os.path.join(carpeta, "quijote.txt")
    if not os.path.exists(ruta):
        urllib.request.urlretrieve(URL_QUIJOTE, ruta)        # se descarga una sola vez
    with open(ruta, encoding="utf-8") as f:
        texto = f.read()
    inicio = texto.index("*** START OF")
    inicio = texto.index("\n", inicio) + 1
    fin = texto.index("*** END OF")
    return texto[inicio:fin].strip()
  • Igual que MNIST en la 1.4: se descarga a data/ la primera vez (excluida del repositorio) y después se lee del disco.
  • encoding="utf-8": los archivos guardan bytes; la codificación dice cómo convertirlos en letras. UTF-8 es la estándar y representa tildes y la ñ. Leer con otra codificación produce “sucedi├│” en vez de “sucedió”.
  • El Proyecto Gutenberg agrega una licencia al principio y al final. texto.index("*** START OF") busca dónde empieza el libro y el slicing texto[inicio:fin] se queda con la parte del medio.

4. Un string es una secuencia

En Python, un texto es un str: una secuencia de caracteres que se indexa y se corta como una lista. len(texto) da 2 110 726 caracteres; texto[0] es el primero; texto.lower() devuelve una copia en minúsculas. Lo que todavía no tiene es estructura: para Python, “Mancha,” es una M, una a, una n… y una coma. Las palabras hay que encontrarlas. Antes, conviene decidir qué diferencias ignorar.
