Instanciar acciones

“Apilar x sobre y” es un esquema; “apilar A sobre B” es una acción concreta. crear_acciones genera todas las combinaciones. Cuántas son, y cuántos estados existen con 3 a 6 bloques.

1. Esquemas y acciones concretas

Un dominio se escribe con variables (x, y, z): una sola definición de “apilar” vale para cualquier par de bloques. Para buscar, en cambio, hacen falta las acciones concretas, con bloques reales en lugar de variables. Generarlas se llama instanciar (en inglés, grounding).

10_agent_planning.py · líneas 56–81
def crear_acciones(bloques):
    acciones = []
    for x in bloques:
        for y in bloques:
            if x == y:
                continue                     # un bloque no va sobre sí mismo
            acciones.append(... apilar(x sobre y) ...)
            acciones.append(... bajar(x de y) ...)
            for z in bloques:
                if z in (x, y):
                    continue
                acciones.append(... mover(x de y a z) ...)
    return acciones

continue salta a la siguiente vuelta del for sin hacer el resto. Las f-strings (f"apilar({x} sobre {y})") arman el nombre reemplazando las variables por los bloques.

Cada bloque que se agrega multiplica los estados por entre 5.6 y 8. Con 10 bloques hay más de 58 millones. Es la explosión combinatoria: el espacio de estados crece mucho más rápido que el problema “parece” crecer. Con 3 bloques, BFS revisa todo sin problema; con muchos, hace falta una heurística (fundamento 7).
