Un modelo de lenguaje como “decidir”

El último escalón del módulo. El ciclo de la 2.1 sigue intacto; lo que cambia es quién decide: un modelo que recibe la tarea en lenguaje natural. Qué gana y qué pierde el agente con eso.

En las lecciones anteriores, alguien tuvo que traducir el problema a algo que un algoritmo entiende: coordenadas, hechos, recompensas. Agente basado en LLM: un programa que repite el ciclo percibir-decidir-actuar donde el paso de decidir es una llamada a un modelo de lenguaje, y las acciones son herramientas que el programa expone. El modelo no actúa en el mundo directamente: pide acciones, y el programa decide si y cómo ejecutarlas.

Esa separación es importante y conecta con la 2.1: el agente (el modelo) y el entorno siguen separados, y toda la comunicación pasa por una interfaz controlada.

4. Dos modos en el script

Llamar a la API real requiere una clave y consume créditos. Para estudiar el ciclo sin conexión, el script trae un LLM simulado: una clase que responde con el mismo formato que la API, siguiendo una estrategia simple. El ciclo del agente no distingue entre los dos: recibe una función decidir y la llama. Los números de estos fundamentos son del modo simulado; las diferencias con el modo real se discuten en cada página.
